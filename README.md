# SQL Analytics Layer

These SQL files are portfolio analysis queries created from the existing Learnofy data model and the synthetic CSV dataset in `data/sample/`.

They are not production SQL files from the original application. The original application uses Django ORM logic for activity summaries, gamification, leaderboard metrics, and cafe promotion metrics.

The SQL is written in a PostgreSQL style because the Learnofy documentation and Django table names reference a PostgreSQL-oriented `app_data` schema.
